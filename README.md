# Avoid AI Writing

Improve natural, clear writing and reduce generic or formulaic AI-generated phrasing.

## Features

- Practical, task-focused instructions.
- Domain-specific workflows and examples.
- Best practices and validation guidance.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/avoid-ai-writing
cp SKILL.md .claude/skills/avoid-ai-writing/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Avoid AI Writing** when handling a related task. Follow the workflow and guidance in `SKILL.md`.
